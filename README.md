# ade-core

**MCP agent-operability layer that exposes ShadowOS to agents.**

| | |
|---|---|
| Layer | L3 — Tool under ShadowOS (L2) |
| Organisation | [Dex-RoboKnix](https://github.com/Dex-RoboKnix) |
| Edition | Core — Open Source |
| Status | Pre-release / In Development |

## Overview

ADE (Autonomous Desktop Environment) is the agent-operability layer of DexRoboKnix. It exposes ShadowOS capabilities to agents through an MCP server, coordinates agent sessions through a DexSpine-aware harness, and gives the human a control UI showing what agents are doing. ShadowOS runs without ADE. ADE requires ShadowOS.

## OpenCore

This is the Core (open source) edition. An Enterprise edition with additional connectors, managed hosting, and commercial support is maintained separately under the same organisation.
